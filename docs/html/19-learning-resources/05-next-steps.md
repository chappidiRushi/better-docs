# 19.5 Next Steps

## Definitions

- **Front-End Development**: The development of the graphical user interface of a website, through the use of HTML, CSS, and JavaScript, so that users can view and interact with that website.
- **Tech Stack**: The combination of programming languages, frameworks, and tools that developers use to build a web application.

## Beginner Level Introduction

Congratulations! By reading through this documentation, you have learned the foundation of the World Wide Web. You now know how to structure a webpage, embed media, and collect data using forms.

However, HTML is only the first step. A modern website requires three core technologies:
1. **HTML**: The Structure (The skeleton).
2. **CSS**: The Presentation (The skin and clothes).
3. **JavaScript**: The Behavior (The muscles and brain).

## Deep Dive

### Step 1: Master CSS

If you haven't already, your immediate next step is to learn CSS (Cascading Style Sheets).

HTML without CSS is just black text on a white background. CSS allows you to:
- Change colors, fonts, and sizes.
- Create complex layouts using **Flexbox** and **CSS Grid**.
- Make your website responsive (so it looks good on a giant monitor and a tiny smartphone) using **Media Queries**.
- Add hover effects and animations.

*Recommendation: Do not learn CSS frameworks (like Tailwind or Bootstrap) until you are comfortable writing plain, "vanilla" CSS.*

### Step 2: Learn JavaScript

JavaScript is what makes the web interactive. It is an actual programming language (unlike HTML and CSS, which are markup and style languages).

With JavaScript, you can:
- Respond to user clicks (e.g., opening a modal window).
- Validate form data before it is sent to a server.
- Fetch new data from the server in the background (AJAX/Fetch) and update the page without refreshing.
- Build complex web applications (like Spotify or Gmail).

*Recommendation: Focus on DOM Manipulation (how JS interacts with HTML elements) and modern ES6 syntax (arrow functions, let/const, promises).*

### Step 3: Git and GitHub

Once you are building projects with HTML, CSS, and JS, you need to save your work securely and share it with the world.

- **Git** is a version control system. It takes "snapshots" of your code, allowing you to undo mistakes and experiment safely.
- **GitHub** is a website where you host your Git repositories. It acts as your professional portfolio when applying for jobs.

### Step 4: Choose a Path (Front-End Frameworks vs. Backend)

Once you have mastered the "Holy Trinity" (HTML/CSS/JS), you reach a fork in the road.

**Option A: Deepen your Front-End Skills**
Learn a modern JavaScript framework like **React**, **Vue**, or **Angular**. These tools allow you to build massive, highly interactive user interfaces much faster than using plain JavaScript.

**Option B: Learn the Back-End**
Learn how servers and databases work. You can use JavaScript on the server using **Node.js**, or learn a new language like **Python**, **PHP**, or **Go**. You will learn how to write APIs, manage user authentication, and query databases (SQL or MongoDB).

## Examples

<details>
<summary><strong>Example: The Front-End Roadmap</strong></summary>

If you are overwhelmed, follow this specific order of topics. Do not skip ahead until you can build a small project with the current step.

1. **HTML Basics** (Tags, Forms, Semantics) -> *You are here!*
2. **CSS Basics** (Colors, Fonts, Box Model, Flexbox)
3. **Build 3 static websites** (Portfolio, Landing Page, Blog Layout).
4. **Git Basics** (Commit, Push to GitHub).
5. **JS Basics** (Variables, Loops, Functions, Arrays).
6. **JS DOM Manipulation** (Event Listeners, `document.querySelector`).
7. **Build 3 interactive websites** (To-Do List, Calculator, Weather App calling an external API).
8. **Learn React or Vue**.
